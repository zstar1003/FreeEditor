# ZIP 导出完整性

文件夹下载和多选下载仍为平铺 ZIP，不改变文章或文件夹数据。原先按标题直接写入 ZIP 会让同名条目覆盖前一篇；现在每篇文章分配唯一名称，冲突时添加 ` (2)`、` (3)` 等后缀。大小写和 Unicode 兼容等价名称也视作冲突，减少常见文件系统解压覆盖。

标题中的路径分隔符、控制字符和 Windows 非法字符替换为 `_`；空标题使用 `未命名`，设备保留名加前缀，长名称截断后仍参与冲突处理。文章正文不改动。单篇下载和 ZIP 包下载名称使用同一安全化规则。

测试仅使用合成文章，生成实际 ZIP 二进制，再用 JSZip 重新打开、校验 CRC、条目数量和每篇全文；包括跨文件夹同名、大小写、Unicode、路径、保留名、长标题、已存在后缀和 500 篇重复名。未测试所有操作系统解压工具或真实用户数据；此补丁无法恢复旧 ZIP 中已被覆盖的文章，应从仍保留的原始文章重新导出。
